# Material surface

`papyrus.webp` was generated for the October 24, 2026 visual revision: pale handmade
papyrus fibers and lime-plaster grain, evenly lit, without drawings, lettering,
darkened edges or ornamental borders. The original generation is preserved in
the task's `generated_images` directory. The WebP is a format-optimized copy.

The interface blends the same low-contrast surface with paper, header and umber
navigation colors. It supplements the existing small contextual illustrations;
it does not introduce a large scene or put text over narrative artwork. Solid
background colors remain available when images are disabled.
