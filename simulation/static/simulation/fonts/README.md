# Alegreya

Self-hosted Latin WOFF2 files for regular, italic and semibold text, from
[`@fontsource/alegreya` 5.2.8](https://www.npmjs.com/package/@fontsource/alegreya).
Alegreya is designed by Juan Pablo del Peral / Huerta Tipográfica and distributed
under the SIL Open Font License; see [OFL.txt](OFL.txt).

The manuscript uses `font-display: swap` and retains Georgia/Times fallbacks.
No runtime font service or external request is required.
